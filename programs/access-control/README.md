# Access Control Program

The main purpose of this program is to handle roles management as well as managing green and black lists. Analog of EVM`s ``MidasAccessControl``

The difference from EVM`s version, is that green and black list is not made in form of roles, in this program green and black lists are moved to a different account. It allows having different access controls for a different Midas Products while still having a shared green and black lists between them.
